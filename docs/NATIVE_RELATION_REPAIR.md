# 原生数值单位与冲突识别修复回归

本轮保持原题、原件SHA和金标不变。测试为CPU原生解析→附件词法检索→Context→真实Qwen tokenizer打包，不调用8B生成、OCR、Planner或付费搜索。75题历史汇总不覆盖，以下是单独的修复回归。

## 通用修复

1. 按原生表格ID、行序与合并列范围收集章节/列头，跨解析块保留对应原始单元格。章节切换清理前一章节的单位，不同列范围不互换单位；不根据问题或金标生成单位。
2. 表头作为来源明确的上下文保留，相关性评分不重复累计其词频；实际数据行与字段/实体绑定共同参与评分，避免只命中标题。
3. Context已排名的局部表格查询不再隐式按首尾窗口重排；显式全文件概览仍使用结构代表证据策略。
4. TXT事实匹配视图只移除已知`[BLOCK id=...]`前缀。保留原文和Evidence ID，不接受未知括号前缀或无实体事实，仍按实体/指标/范围/版本/单位分组。
5. 补入表格上下文时回填真实来源行引用；原始Canonical不修改。
