# 状态与已知限制

[首页](../README.md)

当前持续迭代，尚未完成正式评测；本版没有语义准确率或性能承诺。

- Planner与审核仍可能不稳定，schema合法不证明选对来源/操作；类别仅优先范围。
- 目录/Requirement候选覆盖不证明正文完整、事实支持或已登记全集；表格与条件保留仍需检查。
- 视觉描述有信息边界，外观不能推品牌、材质、保温芯材、防火或耐久性能。标签仅约束未知项，不是身份认证。
- Final可能过度总结、复述宣传或输出内部字段。自然语言契约目前主要非空检查，Prompt禁止泄露不代表程序已可靠拦截；轻量Audit也可能漏检。后续需要通用输出边界校验与独立语义判分，不能靠示意轨迹宣称已解决。
- Audit只检查任务完成、执行一致性和标签边界，不阅读完整原文，fact_support_verified不应被写成true；程序参考来源不是逐句认证。
- 压缩/扩展是CPU结构与相关性策略，不是语义无损算法；即使Token够，内容仍可能不足。
- 多模态Token、格式重试与环境差异仍需真实计数；预算超限应明确失败，不承诺“永远不会超限”。
- Graph没有持久化checkpoint，进程内附件会话在重启后失效。模型独立服务、Qdrant和约束解码需正确配置，默认路径与部署路径要区分。
- Web来源质量、事实时间、正文核验和缓存存在限制；MCP不会改善搜索引擎本身召回质量。
- 本repo不含完整企业语料、权重、索引和运行数据库，企业题需要另行准备有权使用的数据。自造fixture适合工程检查，不代表真实业务分布。

任何新增结果应注明数据版本、代码版本、模型配置、时点、预算、失败/跳过数与独立判分方法，避免把HTTP200、词命中或协议通过当作准确回答。
